# 🔐 PassOP - Password Manager

PassOP is a simple and user-friendly **Password Manager Web Application** built with React.js. It allows users to securely save, view, edit, and delete their website credentials such as website URLs, usernames, and passwords from a single interface.

## 🚀 Features

- 🔐 Save website credentials
- 👁️ Show/Hide passwords
- ✏️ Edit saved passwords
- 🗑️ Delete saved passwords
- 🌐 Store website URLs
- 📋 Easy-to-use user interface
- 📱 Responsive design
- ⚡ Fast and lightweight React application
- 💾 Data persistence using browser local storage

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Vite
- Font Awesome

## 📸 Project Preview

PassOP provides a clean and simple interface where users can add their website URL, username, and password and manage their saved credentials easily.
